# Strict review — 2026-08-16 (security + performance + caching)

Two independent full-codebase audits (security; performance/query/caching) ran
against `feature/redesign` after the CQRS-light pass. Everything CRITICAL/HIGH
/actionable-MEDIUM was fixed in the same-day commits; this file records the
**verdict** and the **deliberately deferred** items so they don't get lost.

## Fixed (see commits of 2026-08-16)

Security: `/metrics` + `/ready` blocked at Caddy (ops-only); product-image
upload got the /media guard set (allowlist + 10MB + magic-byte sniff, plus a
regression test); CSV-import `sku` whitelisted (`[A-Za-z0-9._-]{1,40}` — it
becomes a filesystem path segment); OTP got a DB-backed 5/hour per-PHONE cap
(the slowapi limit is per-IP only) + `10/minute` on verify; chat WS ticket
redacted from Caddy access logs; backups dir 0700; CSP + X-XSS-Protection +
Permissions-Policy added host-independently in Nuxt (Caddy carries fallbacks).

Performance: rate-limit counters moved off the LRU cache Redis onto a
dedicated `redis-limiter` (noeviction) — cache pressure could silently reset
OTP/checkout limits; orders/customers admin lists stopped hydrating unused
child tables (`noload`, measured 300+ wasted rows per orders page);
product cache is now version-keyed and busted by every product mutation +
import completion (paginated keys were unbustable); FAQ mutations bust
`cache:faqs`; `ix_orders_phone` (migration 0029 — /account/orders was a
seq-scan); dashboard scalar KPIs collapsed into one `count(*) FILTER` pass;
product detail sends `Cache-Control`; chat's `ix_conversations_status_last_msg`
declared on the model so autogenerate won't drop it.

## Verified OK (coverage highlights)

Authz on every admin/agent route; ownership (IDOR) checks real everywhere;
no raw SQL; sort whitelists; CSV formula-injection escaped; upload guards on
customer docs + /media; secrets absent from git; prod compose publishes only
Caddy; non-root containers; one-shot migrations; NO N+1s (selectin batches —
measured 6 queries for a 100-row admin page); pool math 40/100 conns;
keyset paging in chat; public products list serves pre-serialized JSON.
