# Hero & product media

Drop real assets here:

- `hero.mp4` — short muted loop of a signature piece (hero background)
- `hero-poster.jpg` — poster / reduced-motion still for the hero

Product images are seeded with remote `placehold.co` URLs; replace via the admin
panel (image upload) or by editing the seed. The hero paths are bound at runtime,
so a missing file degrades gracefully (poster shows the media-surface colour).
