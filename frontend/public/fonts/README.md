# Doran font files

Drop the self-hosted Doran woff2 files here (referenced in `assets/css/main.css`):

- `Doran-Light.woff2` (300)
- `Doran-Regular.woff2` (400)
- `Doran-Medium.woff2` (500)
- `Doran-Bold.woff2` (700)

Until they're added, the UI falls back to Vazirmatn / system-ui via
`font-display: swap` — no build error, just the fallback face.
